    Keys

    / Ctrl K
    search pages
    Enter Shift Enter
    next, previous match
    Esc
    drop words, then key terms, then leave search
    + -
    larger, smaller text
    0
    text of default size
    ?
    this help

    Search

    word
    pages with the word, in title or text
    "exact text"
    pages with the phrase
    key:value
    front matter, e.g. status:draft
    in:folder
    pages under the folder
    is:problem
    pages with problems check reports
    -term
    pages without it

    hover a link
    preview of its target
    sidebar edge
    drag to resize, double click restores
    chip, problem count
